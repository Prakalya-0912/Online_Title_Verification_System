🚀Online Title Verification System
💡 **A Smart Web Application to Verify Project Titles and Prevent Duplicate Project Submissions**

📖About the Project
The **Online Title Verification System** is a web-based application that helps students and researchers verify whether a project title already exists before submitting it.
The system compares the entered project title with the titles stored in the database and instantly informs the user whether the title is **Available** or if a **Similar Title Already Exists**.

✨Features

- 👤 User Registration
- 🔐 User Login
- 📝 Submit Project Details
- 🔍 Verify Project Title
- 📊 Display Verification Result
- 💾 PostgreSQL Database Integration
- 🌐 Responsive User Interface
- ☁️ Cloud Deployment using Render

🔄System Workflow

1. 👤 Register a new account.
2. 🔐 Login using your credentials.
3. 📝 Submit the project title, domain, and description.
4. 🔍 Verify the submitted project title.
5. 💾 The backend compares the title with the PostgreSQL database.
6. 📢 The system displays one of the following results:
   - ✅ Title is Available
   - ⚠️ Similar Title Found
