📖𝓐𝓫𝓸𝓾𝓽 𝓽𝓱𝓮 𝓟𝓻𝓸𝓳𝓮𝓬𝓽
The **Online Title Verification System** is a modern web application that helps students and researchers verify whether a project title already exists in the database before submitting it.
By comparing the entered title with stored project titles, the system quickly informs users whether the title is **Available ✅** or **Similar Title Found ⚠️**.
